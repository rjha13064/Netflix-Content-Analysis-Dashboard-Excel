# Netflix Content Analysis Dashboard - Excel

## Project Overview

The Netflix Content Analysis Dashboard is an interactive Excel project developed to analyze Netflix movies and TV shows.

The dashboard provides insights into content type, release year, countries, genres, ratings and content added over time using PivotTables, PivotCharts and slicers.

## Tools & Technologies

- Microsoft Excel
- Advanced Excel
- PivotTables
- PivotCharts
- Slicers
- Data Analysis
- Dashboard

## Dashboard Features

- Movies vs TV Shows analysis
- Release year trend
- Top 10 countries
- Top 10 genres
- Rating distribution
- Content added by year
- Interactive filters and slicers

## Key Analysis Performed

- Compared movies and TV shows
- Analyzed content trends by release year
- Identified top countries and genres
- Analyzed rating distribution
- Tracked content added over time
